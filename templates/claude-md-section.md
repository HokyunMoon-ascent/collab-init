## human-AI 협업 규칙 (collab-init v2)

이 프로젝트의 인간-AI 인터페이스는 `human 지시 사항 및 결과 파일 모음/` 폴더 하나다. 매 세션 아래 규칙을 따른다.

### 1. 번호는 쌍(pair)에 붙는다
- 하나의 번호는 `input_by_human/`의 폴더 1개와 `output_from_AI/`의 폴더 1개를 **동시에** 가리킨다. 두 폴더 이름은 글자 단위로 동일하다. output만 있는 번호는 존재할 수 없다.
- 다음 번호 = 양쪽 폴더를 **모두** 스캔해 `YYYYMMDD_NN_` 패턴의 최대 `NN` + 1 (없으면 `01`). `_`로 시작하는 항목은 연번에서 제외한다.
- **요청 문서 없이 채팅으로 지시받은 작업**: 산출물을 만들기 **전에** 먼저 같은 번호의 input 폴더와 `request.md`를 만든다. 채팅 지시를 요약해 적고, 머리말에 `> 이 요청서는 터미널 세션 지시를 AI가 옮겨 적은 것입니다. (YYYY-MM-DD)`를 붙인다.
- 사람이 형식을 안 지킨 폴더(예: `새아이디어/`)를 두었으면, 작업을 집을 때 `YYYYMMDD_NN_새아이디어`로 정규화한 뒤 진행한다.

### 2. 요청도 산출물도 폴더
- 요청 진입점은 항상 `input_by_human/<폴더>/request.md`, 산출물 진입점은 항상 `output_from_AI/<폴더>/00_요약.md`. 파일명 고정.
- 참고 소스(이미지·CSV·기존 문서)는 요청 폴더 안에 함께 둔다. 작업 시 그 폴더 전체를 입력으로 읽는다.
- `00_요약.md`에는 무엇을 했는지, 어떤 파일을 어떤 순서로 보면 되는지, 핵심 결론 3줄을 적는다.

### 3. 완료 시 폴더명 확정
- 산출물이 끝나면 주제를 확정해 **input·output 폴더를 같은 이름으로 함께 rename**한다. 한쪽만 바뀐 상태로 끝내지 않는다.
- 형식 `YYYYMMDD_NN_주제` — 날짜는 그 쌍이 처음 만들어진 날(rename해도 안 바뀜), `NN`은 2자리 연번 유지, 주제는 한글 2~5어절을 `-`로 연결(공백 없음, 40자 이내, `/ \ : * ? " < > |` 금지).
- rename 후 문서 안에 옛 폴더명을 참조하는 경로가 있으면 함께 고친다. git 저장소면 `git mv`, 아니면 `mv`. 경로에 한글·공백이 흔하므로 **큰따옴표 필수**.

### 4. 문서 작성
- 사람이 읽을 문서는 담백하게 쓴다. 불릿·이모지·과장 표현 남발 금지, 결론 먼저.

### 5. AI 작업 공간
- 협업 폴더 밖에서는 프로젝트 구조를 자유롭게 구성해도 되지만, 그 구조·설계·프로세스 설명 문서는 해당 요청의 `output_from_AI/<폴더>/` 안에 축적한다. 인간이 이해하지 못하는 파일 난립을 만들지 않는다.
