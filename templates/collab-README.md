# human 지시 사항 및 결과 파일 모음

이 폴더는 이 프로젝트에서 **인간과 AI가 협업하는 단일 인터페이스**다. 인간은 이 폴더만 보면 전체 작업을 파악할 수 있어야 한다.

## 구조

```
human 지시 사항 및 결과 파일 모음/
├── README.md
├── input_by_human/
│   ├── 20260826_01_협업폴더-구조개선/
│   │   ├── request.md                        # 요청 본문
│   │   └── (참고 소스: 이미지·CSV·기존 문서)
│   └── 20260827_02_경쟁사-리서치/
└── output_from_AI/
    ├── 20260826_01_협업폴더-구조개선/          # input과 글자 단위로 동일한 폴더명
    │   ├── 00_요약.md                         # 산출물 진입점
    │   └── (산출물)
    └── 20260827_02_경쟁사-리서치/
```

## human-AI 협업 규칙 (collab-init v4)

### 1. 작업 쌍은 트리 바로 아래에 둔다

하나의 작업은 `input_by_human/` 폴더 1개와 `output_from_AI/` 폴더 1개의 **쌍**이다. 두 폴더의 이름은 글자 하나까지 같다. 폴더 목록을 나란히 놓으면 항상 짝이 맞아야 하고, output만 있는 번호는 존재할 수 없다.

작업 갈래가 뚜렷이 여럿이라 따로 모아 보고 싶을 때만 그룹 폴더로 묶는다(선택). 그룹을 쓰면 경로는 `<tree>/<그룹>/YYYYMMDD_NN_주제/`가 되고, 그룹 폴더는 input·output 양쪽에 같은 이름으로 동시에 만든다. 그룹 안에 또 그룹을 두지 않는다. AI는 사람이 원할 때만 그룹을 만든다.

### 2. 번호 매기기

- 다음 번호는 그 작업이 놓일 **같은 위치**(트리 바로 아래, 또는 해당 그룹 폴더 안)를 input·output 양쪽 모두 스캔해 `YYYYMMDD_NN_` 패턴의 최대 `NN`에 1을 더한다. 하나도 없으면 `01`. 그룹을 쓰면 그룹마다 따로 `01`부터 시작한다.
- 프로젝트 전체 시간순은 번호가 아니라 폴더명 앞의 날짜(`YYYYMMDD`)로 따라간다.
- `_`로 시작하는 폴더는 연번에서 제외한다. 임시 메모나 보관용으로 쓸 수 있다.
- **채팅으로 시작한 작업**: 요청 문서가 없더라도 AI는 산출물을 만들기 전에 같은 번호의 input 폴더와 `request.md`를 먼저 만든다. 채팅에서 받은 지시를 요약해 적고, 머리말에 `> 이 요청서는 터미널 세션 지시를 AI가 옮겨 적은 것입니다. (YYYY-MM-DD)`를 붙여 사람이 직접 쓴 요청과 구분한다. 이 규칙 때문에 input과 output의 번호가 어긋나는 일이 없다.
- 사람이 형식을 안 지킨 폴더(예: `새아이디어/`)를 만들어 두어도 된다. AI가 그 작업을 집을 때 다음 번호로 `YYYYMMDD_NN_새아이디어`로 정규화한 뒤 진행한다.

### 3. 요청도 산출물도 폴더

요청과 산출물 모두 파일 하나가 아니라 **폴더**다. 요청에 참고 자료를 딸려 보낼 자리를 만들기 위해서다.

- 요청은 정해진 양식이 없다. input 폴더를 만들고 하고 싶은 말을 아무 파일에나 적어 두면 된다(`request.md` 권장). AI가 요청서를 대신 만들 때는 `request.md`로 쓴다.
- 참고 소스(이미지·CSV·기존 문서 등)는 요청 폴더 안에 자유롭게 넣는다. AI는 작업 시 그 폴더 전체를 입력으로 읽는다.
- 산출물 진입점은 항상 `00_요약.md`. 무엇을 했고, 어떤 파일을 어떤 순서로 보면 되고, 핵심 결론이 무엇인지(3줄)를 적는다. 산출물이 많으면 하위 폴더로 묶되 진입점은 언제나 `00_요약.md` 하나다.

### 4. 완료 시 폴더명 확정

산출물 작성이 끝나면 AI가 주제를 확정해 **input·output 폴더를 같은 이름으로 함께 rename**한다. 요청 시점의 임시 제목이 그대로 남아 나중에 무슨 작업이었는지 모르게 되는 걸 막기 위해서다.

- 형식: `YYYYMMDD_NN_주제` (예: `20260826_01_협업폴더-구조개선`)
  - `YYYYMMDD` — 그 쌍이 **처음 만들어진 날짜**. rename할 때도 바뀌지 않는다.
  - `NN` — 2자리 연번, 그대로 유지.
  - `주제` — 한글 2~5어절을 `-`로 연결. 공백 없이, 40자 이내, `/ \ : * ? " < > |` 금지.
- rename은 반드시 **쌍으로 동시에**. 한쪽만 바뀐 상태로 작업을 끝내지 않는다.
- rename 후 문서 안에 옛 경로를 참조하는 곳이 있으면 함께 고친다.

### 5. 문서 작성

- 사람이 읽을 문서는 담백하게 쓴다. 불릿·이모지·과장 표현 남발 금지, 결론 먼저.

### 6. AI 작업 공간

- 이 협업 폴더 밖에서는 AI가 프로젝트 내부 구조를 작업하기 편하게 자유롭게 구성해도 된다.
- 단, 그 구조·설계·프로세스에 대한 설명 문서는 작업 폴더 곳곳에 흩뿌리지 말고 해당 요청의 `output_from_AI/<폴더>/` 안에 축적한다.
- 목적: 인간이 이해하지 못하는 파일 난립 방지.

## 사용법

1. `input_by_human/` 안에 폴더를 하나 만들고(이름은 아무거나), 요청과 참고 소스를 넣는다.
2. AI에게 그 폴더를 가리켜 작업을 요청한다. 채팅으로만 지시해도 AI가 요청 폴더를 대신 만든다.
3. 완료되면 `output_from_AI/`의 같은 이름 폴더에서 `00_요약.md`부터 읽는다.
