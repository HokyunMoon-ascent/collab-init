# human 지시 사항 및 결과 파일 모음

이 폴더는 이 프로젝트에서 **인간과 AI가 협업하는 단일 인터페이스**다. 인간은 이 폴더만 보면 전체 작업을 파악할 수 있어야 한다.

## human-AI 협업 규칙 (collab-init v1)

### 요청 → 산출물 라이프사이클
1. 인간이 `input_by_human/NNN_제목.md` 로 작업 요청을 남긴다 (NNN = 3자리 연번, 예: `001_경쟁사_리서치.md`). 양식은 `input_by_human/000_요청_템플릿.md` 참고 (000은 연번에서 제외).
2. AI는 해당 요청의 산출물을 반드시 `output_from_AI/NNN_제목/` 폴더(요청 파일과 동일 번호·제목)에 넣는다. 요청:산출물은 엄격히 **1:1**.
3. 모든 산출물 폴더에는 진입점 `00_요약.md` 를 만든다 — 무엇을 했고, 어떤 파일을 보면 되는지, 핵심 결론 3줄.
4. 산출물 파일이 많으면 `00_요약.md` 에 파일 목록과 읽는 순서를 적고, 필요하면 하위 폴더로 묶는다. 진입점은 항상 `00_요약.md` 하나다.
5. 요청 없이 수행한 작업도 인간이 알아야 할 내용이면 `output_from_AI/`에 새 번호를 부여해 기록한다.

### 문체 규칙 (필수)
- 인간이 읽을 모든 산출 문서(.md 보고서·요약·설명)는 완성 후 반드시 `/humanize` 스킬(Fast 모드)로 윤문을 거친 최종본만 `output_from_AI`에 둔다.

### AI 작업 공간 규칙
- 이 협업 폴더 밖에서는 AI가 프로젝트 내부 구조를 작업하기 편하게 자유롭게 구성해도 된다.
- 단, 그 구조·설계·프로세스에 대한 설명 문서는 작업 폴더 곳곳에 흩뿌리지 말고 해당 요청의 `output_from_AI/NNN_제목/` 안에 축적한다.
- 목적: 인간이 이해하지 못하는 파일 난립 방지.
